- Upstream: https://github.com/mikroverk/esp32sim (the old `joakimeriksson/esp32sim` address opens the same repository)
- Fork: https://github.com/jumperly/esp32sim, branch `jumperly`
- Base: `a3a3102c6c7e130e20a4d5d6e4eb45a68251590c` (2026-10-06) - "wifi: share the station's side of the air between the S3, C3 and C6 (#193)"
- Previous base: `4ab7e900fee998d0137c2c57d59de9d05339d093` (2026-09-23); 130 upstream commits taken (WiFi air sharing, LEDC / MCPWM, SENS ADC, BLE, goldens, UART baud, pin-aware I2C / SPI ...)

- The Jumperly monorepo pins this branch as the `emulator/esp32sim` submodule. `main` on the fork stays even with upstream so GitHub's "Sync fork" only updates that mirror.

## Jumperly patches

Each patched place carries a `Jumperly patch J<n>` comment. To take newer upstream commits, on branch `jumperly`: `git fetch upstream` and `git merge upstream/main`, then resolve. Push `jumperly` and move the submodule pointer in the monorepo. Do not copy files back by hand.

| J12 | new, upstream candidate | `esp-soc/src/nat.rs`, `esp-soc/src/nat/{transport,std_transport,tests}.rs`, `esp-soc/src/net.rs`, `esp-soc/src/net/packet.rs`, `esp-soc/src/wifi.rs` | A pluggable host side for the user-mode NAT, with nothing Jumperly-specific in it (proposed upstream as is). `NatTransport` (`nat/transport.rs`) carries the guest's flows: `tcp_connect` / `tcp_state` (`Connect::Pending`, `Open`, `Failed(ErrorKind)`) / `tcp_read` / `tcp_write` / `tcp_shutdown` / `tcp_close(abort)`, `udp_open` / `udp_send` / `udp_recv` / `udp_close`, `resolver()`, and optional `resolve` / `resolved` (`Resolve::Addrs(addrs, ttl)` or `Failed(rcode)`) plus `incoming` / `incoming_result` for host-initiated flows (defaults: none). J1 covers the unmodelled scheduler (`run_unmodeled`, also with approximate CPI timing); the modelled and approximate-frontier schedulers are not patched - Jumperly never enables them.

The J4 tap is gated: it runs only in Jumperly mode (`esp32sim_jumperly_mode` sets `Console::raw`, `pin_watch`, `rmt_tap` and `pwm_tap`) or on the bus bridges (`esp32sim_bus_host` sets `I2c::defer`, `SocBus::i2c_host` and `SocBus::spi_host`). Upstream's LEDC, MCPWM and SENS ADC models run on every S3 run, as upstream intends.
